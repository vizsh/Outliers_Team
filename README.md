# 🕹️ OUTLIERS CO-OP | 16-Bit Arcade Portfolio & Squad Hub

An authentic gamified 16-bit arcade fighting and collaborative portfolio hub for the engineering squad **OUTLIERS** (**Shreyas**, **Rishit**, and **Jeevesh**).

Built with **React 18**, **TypeScript**, **Vite**, and **Pure Vanilla CSS** (zero Tailwind dependencies), featuring native Web Audio API chiptune synthesis, transparent sprite animations, dynamic combat sequences, shared hackathon campaign quest overworld, and individual 3D OS workspace launchers.

---

## 🌟 Key Highlights

- **Arcade Roster Select**: 3-column "Choose Your Player" cabinet with LED segmented stat meters, sound cues, and cycling keyboard controls.
- **Dynamic 16-Bit Combat Arena**:
  - `[1] LIGHT JAB` (16 DMG, quick dash poke with hit sparks)
  - `[2] HEAVY SMASH` (35 DMG, aerial leap slam with ground shockwaves)
  - `[3] CYBER SHIELD` (-90% damage CI/CD forcefield, perfect parry with +25% Super charge)
  - `[4] 3-HIT COMBO` (48 DMG multi-stage sequence: Parse ➔ Optimize ➔ Deploy)
  - `[5] TECH PROJECTILE` (24 DMG ranged Katana Wave / Chromatic Kunai / Plasma Ball)
  - `[SPACE] SUPER FINISHER` (65 DMG cinematic freeze-frame special move)
  - **Opponent AI**: Counter-attacks, defends with shields, and fires projectiles.
- **Shared Campaign Mode**: Interactive overworld map chronicling flagship team hackathon victories (NeuroScope 3D, Kinesis AI, SIH Enterprise IBVAP) with squad engagement proposal generator.
- **Dual-Track Architecture**:
  - **The Arcade Narrative Track**: Gamified retro fighting experience.
  - **The Fast-Forward Track (`[⚡ FAST MODE (ESC)]`)**: Direct 1-second directory for recruiters with resume downloads, GitHub repos, and discipline filters.
- **Live 3D Portfolio Workstations**: Direct dispatch to [https://updatedportfoliowebsite.vercel.app/](https://updatedportfoliowebsite.vercel.app/) with options for fullscreen new tabs or in-browser retro CRT window preview.
- **Pure Web Audio Synthesizer**: Procedural 16-bit D-minor chiptune arpeggios, parry clangs, impact punches, and victory fanfares without external audio file dependencies.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or pnpm

### Installation
```bash
# Clone repository
git clone https://github.com/vizsh/Outliers_Team.git
cd Outliers_Team

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```

## ⌨️ Controls & Shortcuts

| Key | Context | Action |
|:---|:---|:---|
| `←` / `→` | Roster | Select Squad Member |
| `Space` | Roster | Enter Portfolio Duel Arena |
| `Enter` | Roster | Quick Launch 3D Portfolio |
| `↓` | Roster | Open Shared Campaign Mode Drawer |
| `1` - `5` | Battle | Execute Tactical Combat Moves |
